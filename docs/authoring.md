## 편집 도구

- 코드: Markdown 코드 블록에 `bash`, `yaml`, `text` 등 언어를 지정합니다.
- 사진: Markdown 편집기 상단의 **사진 / 스크린샷 업로드** 버튼으로 이미지 관리자에서 사진을 올려 본문에 삽입합니다.
- 그림: 상단의 **구성도 / 그림 그리기** 버튼으로 diagrams.net 편집기를 열어 네트워크 구성도와 작업 흐름을 그립니다. 저장하면 본문에 삽입되며 미리보기의 그림을 더블 클릭해 다시 편집합니다. 편집기는 온라인 diagrams.net을 사용하고 완성된 그림은 원본 편집 정보를 포함한 PNG로 홈랩 BookStack에 저장됩니다.
- 파일: 첨부 기능으로 설정 예시나 로그를 연결합니다.
- 태그: `기술: OpenStack`, `상태: 해결`, `환경: 홈랩`처럼 이름과 값을 지정합니다.
- 템플릿: 사이드바의 템플릿에서 다른 양식을 선택하거나, `작성 가이드와 양식` 공간의 양식 노트를 직접 편집합니다. 기존 작성 문서에는 수정한 양식이 소급 적용되지 않습니다.
- 에디터: 기본은 Markdown이며 권한이 있으면 편집기 전환 기능으로 시각적 편집기를 선택할 수 있습니다.

## 분류와 공개 범위

화면에서는 작업 공간 → 기술 분류 → 기록 유형 → 작업 노트 순서로 정리합니다. 새 기술은 기술 분류를 추가하고 네 종류의 기록 유형을 만든 다음 편집에서 기본 템플릿을 연결하면 됩니다. 첫 화면도 일반 페이지이므로 편집해 바로가기를 추가할 수 있습니다.

공개 문서는 방문자가 읽고 검색할 수 있습니다. 작성·수정은 로그인 후 권한이 있는 계정으로만 가능합니다. 비공개 자료는 입력 전에 기술 분류 또는 작업 노트의 권한에서 공개 역할의 보기 권한을 해제하고 저장하세요. 스크린샷·로그·설정의 비밀번호와 토큰도 제거합니다.

페이지 템플릿의 동작은 [BookStack 공식 안내](https://www.bookstackapp.com/docs/user/page-templates/)를 따릅니다.

최근에 읽은 항목과 인기 항목 블록은 테마에서 제외했습니다. 작성 중인 초안, 최근 수정한 작업 노트, 변경 이력과 작성 메뉴는 유지합니다. 그림 편집 동작은 [공식 그림·다이어그램 안내](https://www.bookstackapp.com/docs/user/diagrams/)를 참고하세요.
